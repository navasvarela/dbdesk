# Keyboard shortcuts

On Linux and Windows, read Ctrl wherever this page says ⌘.

## Query consoles

These work while the console's editor has focus. They are taken before the editor sees them,
so ⌘↵ runs a statement instead of inserting a new line.

| Shortcut | Action |
| --- | --- |
| ⌘↵ | Run the selection, or the statement at the cursor |
| ⇧⌘↵ | Run every statement in the console |
| ⌘. | Cancel the running statement, or discard rows not yet loaded |

## Editing text

The SQL editor and the other text fields use the usual editing keys:

| Shortcut | Action |
| --- | --- |
| ⌘A | Select all |
| ⌘C, ⌘X, ⌘V | Copy, cut, paste |
| ⌘Z, ⇧⌘Z | Undo, redo |
| ⇧ with arrow keys | Extend the selection |
| ⌥← / ⌥→ (Ctrl on Linux and Windows) | Move by word |
| Tab | Move to the next field (in the SQL editor: insert a tab) |

## Dialogs

| Shortcut | Action |
| --- | --- |
| Esc | Close the dialog without doing anything: the data source dialog, the delete confirmation and the "Run anyway?" check |

Shortcuts can't be changed yet.
