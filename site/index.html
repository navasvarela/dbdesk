dbdesk

Your databases, in one fast native app

dbdesk is a desktop database tool written in Rust. Explore schemas as a tree, write SQL with completion from your catalog, edit rows in the grid, change tables without writing the DDL, and let an AI assistant in only as far as you allow.

Download Read the manual

For macOS and Linux. dbdesk checks for new releases and, on macOS and in the AppImage, installs them itself.

Databases

  • PostgreSQL
  • SQLite
  • MySQL and MariaDB
  • SQL Server
  • DuckDB
  • ClickHouse

Oracle is planned.

What it does

Write SQL

Consoles with highlighting, formatting and completion that knows your tables, columns and aliases. Problems are marked as you type. Run the statement at the cursor or a whole script, explain it, cancel it. Open and save .sql files, fill in :name parameters, find and replace.

Work with results

Rows arrive 500 at a time. Sort and filter the loaded rows, or every row in the database. Edit cells, add and delete rows, and submit them together. Follow foreign keys, export every row to CSV or JSON, and import a CSV file into a table.

Change the schema

Create and change tables, indexes, views and schemas, and PostgreSQL users and roles, from dialogs that show the SQL before anything runs. Copy any table's DDL.

Stay safe

A safety level per data source: normal, careful (every change asks first) or read-only. A check before an UPDATE or DELETE without WHERE, manual-commit transactions, a colour per data source, and a history of every statement, with grid edits' values before and after.

Bring an AI assistant

A built-in MCP server lets Claude, Cursor and other clients list, describe and query a project's data sources, with read, write, schema and admin permissions per project, a row limit and a timeout. It's off until you allow it.

Connect anywhere

SSH tunnels with your agent, a key or a password, and host keys checked against known_hosts. TLS without OpenSSL to install. Passwords stay in your system's keychain. Group data sources into projects, and share them as a file.

Make it yours

Rebind shortcuts in keymap.toml and pick light or dark. On a Mac, the menus are in the menu bar and text is in the system font and accent colour.

Open source

Written in Rust with egui, MIT or Apache-2.0 licensed. The design docs explain how it's built.

Download

Each release has a universal .dmg for macOS 11 or newer, and an .AppImage and a .deb for 64-bit Linux, with a SHA256SUMS file to check them against. Windows builds aren't published yet.
