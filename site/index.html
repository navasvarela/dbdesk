Browse and Query databases

dbdesk is a desktop database tool written in Rust. Explore your schemas as a tree, write and run SQL in consoles that remember your work, and page through, sort, export and edit the results.

Download Read the manual

Packages for macOS and Linux come with each release. Until the first one is out, build it from source.

Databases

  • PostgreSQL
  • SQLite
  • MySQL and MariaDB

SQL Server, DuckDB, ClickHouse, Oracle and others are planned.

What it does

Explore

Databases, schemas, tables, views, functions and their columns, indexes and triggers, loaded as you open them. Filter by name, and read any object's definition.

Write SQL

Consoles with highlighting, completion from your catalog and formatting. Run the statement at the cursor or a whole script, explain it, cancel it. Consoles are saved as .sql files.

Work with results

Rows arrive 500 at a time. Sort and filter what's loaded, copy a selection, view long values, export to CSV or JSON, and edit a table's rows.

Stay safe

Manual-commit transactions, a history of every statement, a check before an UPDATE or DELETE without WHERE, and a colour per data source so production stands out.

Make it yours

Rebind shortcuts in keymap.toml, pick light or dark, and edit the plain files dbdesk keeps its settings in. Passwords stay in your system's keychain.

Open source

Written in Rust with egui, MIT or Apache-2.0 licensed. Small enough to read end to end; the design docs explain how it's built.

Build from source

With Rust 1.95 or newer:

git clone https://github.com/navasvarela/dbdesk.git
cd dbdesk
cargo run --release -p dbdesk-app

The manual covers installing, adding a data source and everything after.
